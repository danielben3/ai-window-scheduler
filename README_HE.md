# AI Window Scheduler — מתזמן AI ל־Windows

כלי שולחני לתזמון בקשות יומיות וחידוש חד־פעמי של שיחות CLI ב־Codex,
Claude Code ו־Antigravity. כולל עברית מימין לשמאל, אנגלית, ערכת צבעים
כהה ובהירה, הגדרות ויומן פעילות מקומי.

**גרסת ניסוי ראשונית v0.1.0.** כל התזמונים היומיים כבויים כברירת מחדל.
זהו פרויקט קהילתי עצמאי. הוא אינו מוצר רשמי של ספקי ה־AI.

[English guide](README.md) · [הורדה](https://github.com/danielben3/ai-window-scheduler/releases)
· [דיווח תקלה](https://github.com/danielben3/ai-window-scheduler/issues)

## התקנה והפעלה

נדרש Windows 10 או 11, עם Python ‏64 ביט בגרסה 3.11–3.15 והפקודה `py`.
האימות המקומי בוצע עם Python 3.14.

1. הורד את קובץ ה־ZIP מההפצות וחלץ לתיקייה קבועה. אל תפעיל מתוך ה־ZIP.
2. הפעל `Setup.cmd`. ההתקנה יוצרת `.venv` ומתקינה את התלות
   `PySide6-Essentials==6.12.0` בנפרד.
3. התקן את כלי ה־CLI הרשמיים שבהם תרצה להשתמש והתחבר באמצעותם לחשבונך.
   אין חובה להתקין את שלושתם. נדרשות הפקודות `codex`, ‏`claude` או `agy`;
   אפליקציה גרפית לבדה אינה מחליפה התקנת CLI.
4. הפעל `Start.cmd`. הממשק נפתח בעברית. במסך **הגדרות** אפשר לבחור
   English, ערכת צבעים, התנהגות סגירה, תדירות רענון והפעלה בכניסה למחשב.
5. בחר שירות ולחץ **בדיקת חיבור**. הבדיקה מריצה `--version` בלבד;
   היא אינה שולחת בקשת AI ואינה מאמתת חשבון. אם הפקודה לא נמצאה,
   הזן נתיב לקובץ exe מקורי או למעטפת ps1 נתמכת.

מעטפת cmd או bat דורשת קובץ ps1 תואם באותה תיקייה. אין צורך בהרשאות מנהל.
שמירת הגדרות שירות שומרת רק את השירות הנבחר. החלפת שפה שומרת טיוטות
בזיכרון; יציאה ללא שמירת השירות מאבדת אותן.

## בקשות יומיות

הזן שעה מקומית, למשל `08:00`, או מספר שעות כמו `08:00, 15:00`, סמן
**הפעלת בקשות יומיות** ושמור את השירות. מודל ריק משתמש בברירת המחדל של ה־CLI.
הבקשה מבקשת תשובת `OK` בלבד ונשלחת בתיקייה נפרדת משירותי העבודה.
Codex פועל לקריאה בלבד; בטריגר Claude מושבתים כלי העבודה וכלי MCP;
Antigravity פועל במצב plan, שאינו מבטיח בידוד של מערכת הקבצים.
כללים, hooks ותוספים קיימים ב־CLI יכולים להשפיע על הריצה ועל הצריכה.

**גם בקשה קצרה עלולה לטעון הקשר גדול.** בניסוי הראשוני נצרכו ב־Codex
24,498 טוקני קלט, מהם 13,440 מהמטמון, וב־Antigravity נצרכו 30,136.
צמצום ההקשר טרם הושלם. בדוק צריכה וחשבון לפני הפעלה יומית.
הכלי אינו מודד טוקנים, אינו עוקף מגבלות ואינו מבטיח התחלת חלון מכסה או
שעת איפוס. רק הספק קובע את חידוש המכסה. ודא בנפרד שה־CLI מחובר לחשבון
ולמסלול החיוב הרצויים.

## חידוש שיחה חד־פעמי

חידוש אמיתי עדיין לא אומת. התחל בשיחה ובתיקיית ניסוי שאפשר לוותר עליהן.
המשך שיחה יכול לערוך קבצים בהתאם להרשאות ה־CLI.

1. צור שיחת CLI והעתק את המזהה המדויק שלה.
2. הזן את המזהה, תיקיית הפרויקט, הנחיה מדויקת ושעת חידוש מקומית.
3. בדוק את **תצוגת הפקודה**, ואז לחץ **תזמון חידוש חד־פעמי**. אם השעה
   כבר עברה היום, התזמון יהיה למחר. בדוק את התאריך שמוצג.
4. לאחר הריצה בדוק את הפרויקט והיומן. הצלחה אינה חוזרת למחרת.

אין בחירה אוטומטית בשיחה האחרונה. שיחות ענן או אפליקציה גרפית אינן בהכרח
נגישות ל־CLI המקומי. רק שגיאות מכסה מוכרות גורמות לניסיון חוזר מוגבל;
שגיאות אחרות עוצרות לבדיקה. Codex ממשיך במצב workspace-write וללא אישורים
אינטראקטיביים; בשאר השירותים נשמרת מדיניות ה־CLI, ללא דגלי עקיפת הרשאות.

**ביטול / עצירה** משפיע על תהליך השירות שהמתזמן הפעיל. הוא אינו מבטל
עריכות שכבר בוצעו. אחרי קריסה נדרשות בדיקה ותזמון מחדש של חידוש שנקטע.

## נתונים וריצה ברקע

הנתונים נשמרים ב־`%LOCALAPPDATA%\AIWindowScheduler`: הגדרות שירותים
ב־`config.json`, הגדרות תצוגה ב־`ui_settings.json`, מצב תזמונים ב־`state.json`,
היסטוריה ב־`history.jsonl` ופלט CLI בתיקיית `logs`.
היומנים וההנחיות עשויים לכלול מידע פרטי; בדוק והשחר פרטים לפני שיתוף.
פרטי ההתחברות נשארים בניהול ה־CLI. משתני סביבה נפוצים של מפתחות API
מוסרים מהתהליך, אך הדבר אינו מאמת בעצמו את מסלול החיוב.

הכלי חייב להישאר פועל כשהמחשב ער והמשתמש מחובר. הוא אינו מעיר את המחשב
ואינו שירות Windows. בקשה יומית שאיחרה ביותר מ־90 שניות מדולגת;
חידוש שאיחר ביותר מעשר דקות דורש תזמון מחדש. השעות הן לפי אזור הזמן
של Windows. עותק אחד בלבד יכול לפעול לכל משתמש.

אפשר למזער ולהמשיך לתזמן. **יציאה** בסרגל הצד מפסיקה את הכלי גם אם
הוגדר מזעור בעת סגירה. הפעלה בכניסה למחשב היא אפשרות נפרדת; לאחר העברת
תיקיית הכלי יש לרשום מחדש את קיצור הדרך. להסרה: בטל פעולות והפעלה בכניסה,
צא מהכלי ומחק את תיקייתו. אפשר לשמור או להסיר בנפרד את נתוניו המקומיים.

## מה נבדק

20 בדיקות מקומיות מכסות מניעת כפילות, ניסיונות חוזרים מוגבלים, ביטול,
טיפול בקריסה, שפות ושמירת הגדרות. הן אינן שולחות בקשות AI.
ב־26 באוקטובר 2026 נבדקו במחשב Windows אחד בקשה אמיתית ב־Codex וב־Antigravity:
כל אחת החזירה OK בבקשה אחת. ב־Claude Code אומת זיהוי גרסה בלבד.
חידוש שיחות, שעת איפוס מכסה וקיצור הדרך בכניסה ל־Windows טרם אומתו מקצה לקצה.
גרסאות ה־CLI והפקודות עלולות להשתנות. פתח את תוכנית הניסוי המובנית
לאימות במחשב שלך. פקודת הבדיקות מופיעה ב־[מדריך באנגלית](README.md).
